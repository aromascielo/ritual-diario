## Pasos pendientes para vos

### 1. Darle permiso a Claude para subir cambios a GitHub (5 minutos)

El repositorio `ritual-diario` ya está creado. Falta instalar la app de Claude en GitHub para que pueda guardar ahí el código.

1. Entrá a **https://github.com/apps/claude/installations/select_target** (con la cuenta `aromascielo`).
2. Elegí la cuenta **aromascielo**.
3. En "Repository access" elegí **Only select repositories** y marcá **ritual-diario**.
4. Tocá **Install** (o **Save**).
5. Avisale a Claude "listo el permiso de GitHub".

### 2. Instrucciones del Proyecto en claude.ai

1. En claude.ai abrí el Proyecto **App Aromas Cielo**.
2. Buscá **Instrucciones del proyecto** (o "Set project instructions") y tocá para editar.
3. Abrí el archivo `docs/instrucciones-proyecto.md` de esta carpeta, copiá todo el texto que está entre las dos líneas `---` y pegalo ahí.
4. Guardá.

---

## Cómo se prueban los cambios

No necesitás instalar nada. Cada cambio se publica en una **dirección de prueba** (una página web aparte) que abrís en el celular.
La app real recién se actualiza cuando vos decís que está bien.
